## Limits and privacy

The repository remains private. Secret/backup/runtime directories, recovery bundles
and private recovery identities are excluded. No history rewrite or tag movement
is part of this patch. Git author metadata requires owner review before a future
public-visibility decision.

Manual LUKS unlock, defective battery, manual power restoration, local-only alerts,
manual backups without guaranteed RPO/RTO, no independently verified geographically
separate offsite backup, deferred centralized logging and no separate clean-host
deployment remain accepted. Historical recovery evidence was not rerun. See
[limitations](../LIMITATIONS.md) and [evidence](../TEST-EVIDENCE.md).
