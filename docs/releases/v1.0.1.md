Both must pass at the released commit before public visibility. Exact run links and

from this successor. Architecture diagrams, six-panel dashboard source and local
documentation links are retained. No screenshot has been fabricated.

## Limits and privacy

The original repository remains a private archive. This successor is published only
after source, metadata, refs, release and both CI jobs pass verification. No secret,
backup, runtime state, recovery bundle, private identity or personal email-bearing
commit is imported. `v1.0.1` is a new annotated successor tag; the original private
release stays in the archive. `v1.0.0` is unchanged.

Manual LUKS unlock, defective battery, no automatic power restoration, local-only
alerts, manual backups without guaranteed RPO/RTO, no independently verified
geographically separate offsite backup, deferred centralized logging and no separate
clean-host deployment remain accepted. Historical recovery evidence was not rerun.
See [limitations](../LIMITATIONS.md) and [evidence](../TEST-EVIDENCE.md).
