# v1.0.0 — historical release

The IT Operations & Automation Lab demonstrates operating a private Debian/Docker
monitoring environment: host observability, HTTP/TCP diagnostics, incident handling,
controlled changes and encrypted backup recovery. Final local security and quality
gates passed at the reviewed release commit
`1f4af30dbfbb02331d886e1605b11a643f7ab3e6`. The annotated `v1.0.0`
tag is preserved in the successor and remains fixed at that commit.
These notes distinguish the original evidence from subsequent CI improvements.

## Included demonstrations

- Grafana 13.3.1, Prometheus 2.55.1, Node Exporter 1.8.2, Blackbox Exporter 0.27.0.
- Provisioned six-panel dashboard, seven expressions, seven scrape targets, four
  probes and three alert rules tested for delay, firing and recovery.
- Real stopped-exporter alert exercise and Grafana provisioning-permission incident;
  isolated HTTP/TCP/DNS simulations with documented scope.
- Bash and PowerShell diagnostics, twelve Bash cases, nine historical user-executed
  Windows cases, and three new isolated backup failure-path tests.
- Configuration/state backups, encrypted off-device workflow, USB recovery identity
  test per user report, and isolated Grafana/Prometheus restore verification.
- Fresh-credential installation, runbooks, evidence provenance, security review,
  privacy-sanitized five-commit history and lightweight CI configuration.

## Accepted limitations

Single host, defective battery, manual LUKS unlock, no automatic power restoration,
deferred centralized logging, local-only alerts, manual backups, no guaranteed
RPO/RTO and no independently verified geographically separate offsite protection.
Docker logs and metric disk growth require manual capacity management. These do
not block the supported v1.0 lab scope. See [limitations](../LIMITATIONS.md).
